## 一句话总览

Scoopic 当前不在「大规模买量 + 公开 feed 爆款」阶段，而是：

> **用付费校园节点（UGC Creator + Campus/Greek Ambassador）制造可传播内容与密友小组成组激活，同时用 App Store 免费 Pre-Order 囤启动日下载意图；产品预计 2027-01-01 前后正式可用。**

核心增长公式（推断）：

```
付费创作者日更短视频（TikTok + Reels）
  × 校园地推/派对植入（Greek Life 等）
  × 「≥5 密友」强制成组 + $20 合格邀请
  → 预购名单 / 早期小组密度
```

## 3. UGC Creator 机制（内容增长引擎）

### 3.1 工作设计
- **每天 1 条**短视频（约 10–40 秒），**同一条交叉发 TikTok + Instagram Reels**
- **不发个人号**：用新 Gmail 开专用 Scoopic TikTok / IG，品牌账号矩阵由创作者代运营
- 内容母题：真实朋友局、camera-roll lore、校园梗、对 Scoopy 的真实反应
- 要求 **至少拉 5 个真实朋友一起用**，并交周反馈（产品调研内嵌在增长里）

### 3.2 激励设计（公开阶梯）

| 单条播放量 | 奖金 |
|------------|------|
| 50K | $50 |
| 100K | $100 |
| 500K | $300 |
| 1M | $500 |
| 2M | $1,000 |
| 5M | $2,000 |

- FAQ：**奖金按达标视频叠加、不设「条数上限」** → 明确押「爆款期权」
- 另：**每位通过验证的合格学生好友约 $20**

### 3.3 策略含义
1. **供给侧外包**：用保底换稳定日更，用爆款奖金换注意力期权  
2. **账号隔离**：降低个人账号风险，便于品牌统一声量  
3. **内容即获客漏斗**：视频 → 好奇 → Pre-Order / 申请 / 邀请密友  
4. **产品共创**：周反馈把种子用户变成研究样本

约 **5 hr/week**（OnCampusNation）说明岗位按「半兼职创作者」设计，可规模化复制到多校。

## 4. Campus Ambassador 机制（场景与信任增长）

### 4.1 定位文案
- Hero：**Bring Scoopic Into Greek Life**
- 动作：在 chapter / mixer / philanthropy / game-day / dorm hangout 等**已有聚会**里植入，而不是另办「Scoopic 专场」
- 交付：演示 App、收集反应、小规模 giveaway / activation、把现场变成短内容

### 4.2 运营规则（FAQ）
- 不必必须 Greek Life，但欢迎跨组织多大使
- 每周约 **1–5 小时**；多做 activation 可多赚
- **双周发薪**；按 activation 类型与表现计酬
- **预批费用可报销**，不从个人薪酬扣
- 按 **学期**签约，表现好可续

### 4.3 策略含义
密友产品最怕「一个人下载没人玩」。Campus 轨解决的是：

> 在高信任、高共现场景里，当场把一桌人变成小组。

与 UGC 轨形成互补：**线上注意力 × 线下成组**。

## 5. 产品内置的增长钩子（App Store 文案）

官方描述把增长写进玩法：

1. 喂 puppy 当天照片  
2. puppy 找出值得 report 的瞬间  
3. **每天回来看朋友们的 scoop**  
4. **点 pin/spot 揭秘**  

约束：
- **最多约 20 密友**  
- 默认私密  
- 无「表演型完美发帖」压力  

→ 传播路径更可能是 **小组内炫耀 / 八卦转述**，而不是公开关注者裂变；因此他们才把钱砸在 Creator 外循环 + Campus 内循环，而不是纯 ASA 泛投（至少公开侧看不到后者为主）。

隐私标签显示会处理 Contacts、Photos、Identifiers 等——与「通讯录/相册驱动的密友邀请」一致（合规沟通是后续风险点）。

## 8. 策略评价（产品视角）

### 做得聪明的地方
1. **先密度后规模**：强制 5 人小组 + 20 人上限，增长目标是「活小组」不是「空壳 DAU」  
2. **把 CAC 变成内容资产**：Creator 日更同时完成品牌与教育  
3. **场景选 Greek Life / 派对**：天然高共现、高拍照、高八卦，和 paparazzi 隐喻同构  
4. **Pre-Order 对齐 2027-01-01**：给内容与校园网一个明确 Launch 倒计时  
5. **双周结算 + 报销**：降低大使执行摩擦

### 风险与张力
1. **单位经济极重**：一名 Creator 保底 $500 + 爆款奖金 + $20 邀请；若转化不成组，烧钱很快  
2. **账号矩阵依赖**：专用 TikTok/IG 冷启难，爆款方差大  
3. **隐私叙事敏感**：相册狗仔 + Contacts，需极强信任与合规文案  
4. **开学招聘窗口短**：2026-08–09 批量挂岗，错过学期节奏会断粮  
5. **上线日遥远（估 2027-01-01）**：预购到可用间隔长，需持续内容保温，否则预购名单衰减
